# 所有角色共享同一份用户记忆，每条记忆标注来源角色

关于同一位用户的记忆由所有角色共享，而不是每个角色各存一份；每条记忆都记录这件事是对哪个角色说的。其他角色提到这件事时，会以转述的口吻说出（例如「听灯织说你感冒了」），不会说成是用户亲口告诉自己的。用户叮嘱「别告诉某某」的内容也照样共享：这是有意为之的简化，因为同一事务所里的偶像之间本来就会互相交流。

## Consequences

- 不支持「只有某个角色知道」的私密记忆；如果以后需要，就给记忆加一个可见范围字段，不用改动共享模型。

**后续（2026-11）**：记忆已经加了 `private` 可见范围，记忆页也按主人分成了公共记忆 / 角色记忆，见 ADR-0033。公共仍是默认，共享模型不变。
