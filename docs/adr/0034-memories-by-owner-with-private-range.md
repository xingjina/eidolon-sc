# 记忆页按主人分组：公共记忆是所有主人的合集，角色记忆只放她自己的

记忆仍然是「一条记忆有一个来源角色（主人），公共/私有只是可见范围」。设置里的「记忆」分成两个 Tab：

- **公共记忆**：所有主人的公共记忆放在一起，一行一条，和原来的记忆列表一样。
- **角色记忆**：先选一位有自己记忆的角色，再看她自己的公共记忆和私有记忆。私有行是 `rounded-xl` 的圆角块，铺她的颜色；公共行无色。列表上方有「全部 / 公共 / 私有」过滤，所有角色共享这个过滤状态。

角色记忆里**不出现**别的角色的公共记忆。这一页回答的是「我和她之间有哪些记忆」，不是「她现在能想起什么」：聊天时她仍然会以转述的口吻知道别人的公共记忆，但那些记忆不放进她的角色记忆列表。只列有自己记忆的角色，一条自己的记忆都没有的角色不出现，避免角色条变成一长串 0 条。

改可见范围仍然用原来的铅笔 + 编辑弹窗，只改这一条的 `private`，不换主人：公共页里改成私有会让它离开公共页、回到主人的角色记忆并带颜色；在角色记忆里改只换颜色。编辑弹窗的入口和结构不变。

## Considered Options

- **一列混排（现状）**：改动最小，但公共和私有混在一起，私有记忆只能靠一个徽章认出来，也不方便按角色看。
- **每个角色的页面放「全部公共 + 她的私有」**：能完整呈现「她现在能想起什么」，但整份公共列表会复制到每位角色下，二十多位角色翻起来都是同一堆公共记忆。没有采用。
- **把角色记忆做成只装私有记忆**：页面最短，但公共记忆在角色页里看不到，改公共/私有后行会跨页跳，不符合「两种显示在一起、用颜色区分」的要求。

## Consequences

- 公共记忆页是全部公共记忆的唯一全集；角色记忆页是「她自己的」子集。两者会有重叠（她自己的公共记忆），这是有意的。
- 记忆页的角色头像用肖像，不受「外观 - SCSP 头像」影响；其他页面照旧。
- 导入数据包时必须保证每条记忆的主人都在当前角色配置里：未知来源的记忆跳过并报告条数，否则私有记忆会没有角色条可进、看不见也删不掉。数据包格式 6 起带上 `private`。
- `GLOSSARY.md` 的「记忆」拆出「公共记忆」「私有记忆」两条；隐私政策的「记忆」一条同步改写。
